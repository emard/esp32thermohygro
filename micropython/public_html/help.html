NOTE

Calibration is a piecewise linear interpolation that applies to log.
Values outside of "In" domain range are logged as direct readings from sensors without calibration.
Values on hardware display and web page are direct readings from sensors without calibration.
At least 2 points are required for calibration to take effect.

New SHT85 sensors have serial number as 8-digit hex number
Each SHT85 sensor can have its own calibration table.

Old SHT75 sensors don't have serial number.
Every SHT75 sensor serial number appears as 00000000.
There can be only one calibration table for serial number 00000000
and it will apply to every SHT75 sensor.
